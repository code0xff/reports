# Uncertainties

- mppx's identity PRs (#1240, #1250, #1258, #1264) all shipped with open automated-reviewer findings at the time of capture — ranging from a High-severity note that an attestation can expire between the 402 challenge and the paid retry, to several Medium/unverified items about fallback behavior and header compatibility. The feature set is merged but not yet settled; a later edition should check whether these findings closed or whether behavior changed in response.
- "Agent identity" is a loose label for this arc. Three of the four mppx PRs verify a human (an email owner, a KYC'd person, or the generic attestation substrate); only the Link integration (#1258) is explicitly about verifying an agent as such. Treat the arc as "identity and payment-gating infrastructure that agents will also use," not as "mppx solved agent identity."
- OpenAI's eligibility bar for Business Agents ("eligible US ecommerce and online-service businesses") is not defined further in any source this harness read; neither Unite.AI nor TNW describes the actual approval criteria, and OpenAI's own page was unreachable. Treat "eligible" as OpenAI's own unexplained term. _(vendor-stated)_
- Adobe's MCP server scope is based on one TechCrunch article naming Illustrator, Photoshop, After Effects, and Premiere; Adobe's own product/developer documentation for the MCP server was not independently checked, so the exact tool surface (which actions, which apps, local-only vs. hosted) is taken on TechCrunch's reporting alone. _(unverified — single source for scope details, though the launch itself is independently reported)_
