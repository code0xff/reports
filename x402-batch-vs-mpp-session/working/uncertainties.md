# Uncertainties

- **batch-settlement launch date (2026-05-13)** — sourced from Cointelegraph [s07], vendor-amplified; the x402 announcement page (`x402.org` writing index) is partially access-limited.
- **TypeScript / Go implementations completeness** — Cointelegraph [s07] reports TS + Go available, Python coming. The exact npm package and module entry for batch-settlement is referenced but not fully transcribed.
- **MPP session contract addresses** — already published in the existing `mpp-session-mechanism` report; not re-fetched in this comparison and therefore not citable as a fresh primary source here.
- **x402 vs MPP convergence** — purely interpretive. The PR-level evidence (e.g. the EIP-4337 UserOperation issue [s30]) suggests integration of orthogonal scheme types is on the roadmap, but no merged convergence work exists.
- **mpp-rs vulnerability advisory [s31]** describes a specific implementation flaw in one Rust SDK; it should not be read as a flaw in the MPP session protocol itself, only in that particular implementation.
