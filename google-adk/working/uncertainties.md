# Uncertainties

- **명칭 전환기**: 배포 대상이 문서에 따라 "Vertex AI Agent Engine"(2025 발표, s17)과 "Agent Runtime on Agent Platform"(현행 adk.dev, s11)·"Gemini Enterprise Agent Platform"(s21)으로 혼재 — Google Cloud 제품 리브랜딩 진행 중으로 보임. 보고서는 두 명칭을 병기.
- **Kotlin SDK 지위**: adk.dev는 5개 언어를 내걸지만 Google Cloud 문서(s21)는 4개만 언급; adk-kotlin은 119 스타, sessions 문서에 "Kotlin v0.1.0" — 매우 초기 단계.
- **ADK 2.0 아키텍처 전환**: "hierarchical agent executor → graph-based execution engine" 전환(s13)은 최근(Python 2026-05, Go 2026-06)이라 마이그레이션 실태·안정성에 대한 독립 평가가 아직 없음.
- **경쟁 비교의 시효**: 비교 소스(s22, s23)는 개인/기업 블로그로 스타 수 등 수치가 시점에 따라 이미 어긋남; 정성 평가만 인용.
- **TS/JS와 Kotlin의 그래프 워크플로 지원**: graphs 문서(s05)는 Python/Go 2.0만 명시 — 다른 언어의 2.0 로드맵 미확인.
