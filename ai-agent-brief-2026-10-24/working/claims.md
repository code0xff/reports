# Claims — ai-agent-brief-2026-10-24

- c01: Security researchers reproduced (3/3 sessions, Base Sepolia, 2026-10-21) an overcharge against the official x402 v2 TypeScript client (`@x402/fetch` + `@x402/core` + `@x402/evm` 2.28.0): a resource server that inflates the 402 payment requirement to 10x the resource's real price gets paid the inflated amount, because the client has no built-in way to check the server's declared price against an independent expectation — only the caller's spend cap limits the damage.
- c02: In the GitHub issue thread, a production operator (gobeyondfj-cmd) demonstrated a working mitigation pattern — binding an `expected_amount` at mandate-issuance time (signed by the wallet owner, not learned from any server response) and vetoing before the EIP-3009 signature is created — but this is not the x402 client's documented default behavior as of 2026-10-23.
- c03: `@x402/core` 2.28.0 pins `zod ^3.24.2`, which carries GHSA-mrhx-c7xc-m3w5 (CVE-2023-54404, CVSS 7.5, high) with no fix in any 3.x release — only in zod 4.6.6 — so any project depending on `@x402/core` that runs `npm audit --audit-level=high` in CI must either fail the build or allowlist the advisory indefinitely.
- c04: The reporting engineer traced the vulnerable code path to two exported helper functions (`isPaymentRequiredV1`/`V2`) that validate an unbounded `accepts` array from an untrusted server; as of the issue's filing (2026-10-23) no internal x402 call site was found to invoke them on untrusted input, so the exposure is scoped to third-party code that imports those helpers directly. _(unverified — single source, open issue)_
- c05: OpenAI made its Decisions API generally available to all customers on 2026-10-22 (first announced 2026-09-29), repurposing its ChatGPT Luna model for faster inference rather than training a dedicated decision model, cutting reported response times from 1-3 seconds to roughly 100-180 milliseconds.
- c06: TypeSafe's Jev, a dedicated "decision model" built as a fast classifier rather than a general LLM, ranks ahead of OpenAI's Decisions API on two of the industry's early decision-model benchmarks (AIM System One Index, Artificial Analysis Decision Index) as of this window, with neither OpenAI nor independent reviewers claiming an industry-standard benchmark yet exists for the category. _(vendor/benchmark-stated)_
- c07: Trial customer Speak reported the Decisions API cut the time between agent actions in its production loop from 1.4 seconds to 0.13 seconds, illustrating why a dedicated low-latency decision layer — not a general LLM call — is becoming infrastructure for multi-step agent action loops. _(vendor-stated, single customer anecdote)_
- c08 (why it matters): The x402 overcharge finding (c01) is a concrete, exploitable instance of the gap Stripe's Money20/20 recap named in the prior brief — a payment credential proves an agent can spend, not that the amount matches what the consumer actually authorized — surfacing in the most widely adopted agent-payment protocol rather than as an abstract industry concern.
- c09 (why it matters): The decision-model race (c05-c07) shows that outside the payments/identity stack, the fastest-moving competitive axis in agent tooling this window is still raw cost and latency per agentic step, not safety or correctness.
