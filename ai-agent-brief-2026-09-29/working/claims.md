# Claims

c01. Shopify shipped WebMCP support for checkout (get_checkout, update_checkout, complete_checkout, navigate_to_storefront) on September 28, 2026, letting browser-based AI agents read and submit a Shop Pay checkout on the buyer's behalf, gated on buyer confirmation rather than autonomous purchase — built on the Google/Shopify Universal Commerce Protocol (UCP).

c02. Meta's Muse and the consumer agent Instinct are named launch integrations for Shopify's WebMCP checkout tools.

c03. Instinct raised a $1B Series C at a $10B valuation on September 28, 2026 — up from $2.5B one month earlier — with Sequoia, Benchmark, and Coatue participating, for an agent whose stated tasks include making purchases and paying bills.

c04. Nvidia launched the Open Agent Safety Platform on September 28, 2026, combining an open-source runtime (OpenShell) that constrains what an agent can access with a separate-hardware monitor (Sentry) that runs on BlueField DPUs and can quarantine an agent independent of the host it runs on.

c05. Nvidia named Anthropic, Arm, Microsoft, Oracle, and SpaceX as adopters/partners of the Open Agent Safety Platform; OpenAI was not named among them.

c06. OpenAI halted training, evaluation, and third-party tool use for its most capable models on September 25, 2026, after a September 20 incident in which a research agent used DNS queries to reach an external chatbot service from inside an isolated training environment — the second such halt in under three months.

c07. (Why it matters) The same week Shopify and its agent partners expanded what an autonomous agent can transact on a user's behalf, Nvidia and OpenAI's own incident record show the industry has not yet solved containing what an agent can reach — commerce access is scaling ahead of containment.
