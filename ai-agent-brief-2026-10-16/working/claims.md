# Claims

- c01: Google's OAuth platform added DPoP (RFC 9449) key-binding for refresh tokens on 2026-10-15, moving agent-identity validation at Google's Agent Gateway from bearer tokens toward proof-of-possession, while access tokens stay bearer tokens for performance.
- c02: Google's multi-agent delegation guidance requires an intermediate agent to exchange an upstream token through Cloud STS for a new key-bound token rather than share its private key — a concrete answer to the "who is actually calling" problem this brief has tracked since September, built on OAuth infrastructure rather than a named agent-identity spec.
- c03: Figma's October 14 Config India event moved its agent-on-canvas feature from limited to wider availability and expanded Figma MCP to 20+ third-party tool integrations, making design context (libraries, specs, guidelines) machine-readable for agents rather than just human-readable.
- c04: At Stripe's Monetize 2026 conference (recapped 2026-10-13), AI companies described abandoning flat subscription pricing for usage-based and outcome-based models tied to agent work — Replit's per-checkpoint billing had to be re-priced as agent runtimes grew past the economics of a flat 25-cent charge. This shift is not frictionless: GitHub Copilot's June 2026 move to usage-based billing triggered an immediate customer backlash over unpredictable costs.
- c05: The same Stripe recap reports an analysis of 7,600 AI-generated pricing answers across six AI engines found one unnamed company's pricing cited negatively in 88% of responses, with LLMs sourcing informal estimates ranging $100-$2,400/user/month — a 24x spread — when official pricing wasn't machine-readable. _(single source, unverified methodology)_
- c06: Third Moment Research, an OpenAI customer, runs up to 10,000 agents concurrently on investigations lasting 36-48 hours using Codex and GPT-6-family models, with Codex itself finding and deploying an optimization that cut a backtesting bottleneck from ~3 hours to ~3-5 minutes. _(vendor-stated, single source — OpenAI's own customer-story post)_
- c07 (why it matters): This window's motion sits one layer away from the payment specs themselves — OAuth-based agent identity, design-tool agent integration, and agent billing economics — while x402 remains the only one of the seven tracked payment specs with visible activity, and even x402 produced no new motion this window beyond what the prior edition already covered.
