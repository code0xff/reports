# Claims — 신용정보법과 Agent Payments

## 배경: 법의 구조와 규율 대상
- [ ] c01: 신용정보법상 "신용정보"는 식별정보(§2(1)가)만으로는 성립하지 않고
  거래내용·신용도·신용거래능력 등 정보와 결합될 때에만 신용정보에 해당한다.
  - kind: technical
  - needs: 법 §2(1) 원문
- [ ] c02: "신용정보회사등"에는 신용정보제공·이용자가 포함되므로, 금융회사가
  아닌 일반 사업자도 개인신용정보를 처리하면 이 법의 의무 주체가 된다.
  - kind: technical
  - needs: 법 §15① 정의 부분 원문
- [ ] c03: 신용정보업·본인신용정보관리업·채권추심업은 금융위 허가 없이
  영위할 수 없고, 위반 시 형사처벌 대상이다.
  - kind: technical
  - needs: 법 §4①②, §50②1 원문
- [ ] c04: "처리"의 정의가 수집·생성·연계·연동·기록·저장·보유·가공 등을
  포괄하므로, 에이전트가 데이터를 읽어 판단에 쓰는 행위는 처리에 해당한다.
  - kind: technical
  - needs: 법 §2(13) 원문

## 데이터 취득 경로
- [ ] c05: 개인인 신용정보주체는 전송요구권(§33조의2①)을 통해 본인·
  본인신용정보관리회사·개인신용평가회사 등 열거된 자에게만 전송을 요구할 수
  있고, 임의의 제3자를 수신자로 지정할 수는 없다.
  - kind: technical
  - needs: 법 §33조의2① 원문
- [ ] c06: 전송요구 대상 정보에서 신용정보제공·이용자등이 개인신용정보를
  기초로 별도로 생성하거나 가공한 정보는 제외된다.
  - kind: technical
  - needs: 법 §33조의2②3 원문
- [ ] c07: 본인신용정보관리회사가 신용정보주체의 접근매체를 보관·접근권한
  확보·사실상 지배하는 방법으로 위임·대리·대행 방식으로 신용정보주체의
  이름으로 열람하여 정보를 수집하는 것은 금지된다.
  - kind: technical
  - needs: 법 §22조의9③ + 시행령 §18조의6③ 원문
- [ ] c08: 접근매체는 전자금융거래에서 거래지시를 하거나 이용자·거래내용의
  진실성·정확성을 확보하기 위해 사용되는 수단·정보로 정의되어, 결제 실행
  권한과 데이터 열람 권한이 같은 매체에 겹쳐 있다.
  - kind: technical
  - needs: 전자금융거래법 §2(10) 원문
- [ ] c09: 따라서 사용자의 로그인 자격증명을 보관해 금융기관에 접속하는
  에이전트는, 허가를 받으면 §22조의9③에 걸리고 허가를 받지 않으면 §4①에
  걸리는 양방향 제약에 놓인다.
  - kind: interpretive
  - needs: c03, c07의 결합 + 반대해석 가능성 검토

## 대리인 구조
- [ ] c10: 신용정보법은 신용정보주체가 전송요구·자동화평가 설명요구·동의철회·
  열람정정 등의 권리를 대리인에게 하게 할 수 있음을 명시한다.
  - kind: technical
  - needs: 법 §39조의3① 원문
- [ ] c11: 그 위임은 서면·전자문서·홈페이지·애플리케이션·메신저 등 안전성과
  신뢰성이 확보되는 수단으로 하되 대리의 구체적 내용·범위·기간을 포함해야
  한다.
  - kind: technical
  - needs: 시행령 §34조의3 원문
- [ ] c12: 시행령은 본인신용정보관리회사가 권리의 대리행사를 강요하거나
  부당하게 유도하는 행위를 금지하는데, 이는 대리행사 자체가 제도적으로
  허용됨을 전제한다.
  - kind: interpretive
  - needs: 시행령 §18조의6①3 원문
- [ ] c13: 동의 없이 전송요구 내용을 변경하거나 본인이 요구한 범위를 초과해
  개인신용정보를 요구하는 행위는 금지되므로, 에이전트의 권한 범위는
  런타임에 확장될 수 없다.
  - kind: technical
  - needs: 시행령 §18조의6①10 원문

## 위탁 구조
- [ ] c14: 신용정보 처리를 위탁받은 수탁자에게는 안전보호·행위규칙·금지사항·
  손해배상·감독 관련 조항이 벌칙·과태료를 포함해 준용된다.
  - kind: technical
  - needs: 법 §17② 원문
- [ ] c15: 수탁자는 위탁받은 업무를 제3자에게 재위탁할 수 없고, 금융위원회가
  인정하는 경우에만 예외가 인정된다.
  - kind: technical
  - needs: 법 §17⑦ 원문
- [ ] c16: 위탁자는 수탁자에게 개인신용정보를 제공할 때 식별정보를 암호화해야
  하고, 수탁자를 교육하며 안전처리 사항을 위탁계약에 반영해야 한다.
  - kind: technical
  - needs: 법 §17④⑤ 원문

## 자동화평가
- [ ] c19: 자동화평가는 종사자가 관여하지 않고 정보처리장치로만 개인인
  신용정보주체를 "평가"하는 행위로 정의되므로, 결제의 자동 실행 자체와는
  구별된다.
  - kind: technical
  - needs: 법 §2(14) 원문
- [ ] c20: 자동화평가 대응권의 적용 국면에는 개인신용평가뿐 아니라 대통령령이
  정하는 금융거래의 설정·유지 여부와 내용의 결정이 포함된다.
  - kind: technical
  - needs: 법 §36조의2①1 + 시행령 해당 항 원문
- [ ] c21: 설명 대상에 자동화평가의 결과·주요 기준·기초정보 개요가 포함되지만,
  금융회사 등이 기초정보를 자체적으로 가공하여 생성·추론한 정보는 설명에서
  제외할 수 있다.
  - kind: technical
  - needs: 법 §36조의2①2 + 시행령 원문
- [ ] c22: 동일 금융거래에 대해 정당한 사유 없이 3회 이상 반복 행사하는 경우
  등에는 요구를 거절할 수 있다.
  - kind: technical
  - needs: 시행령 원문
