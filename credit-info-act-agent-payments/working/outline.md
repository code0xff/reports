# Outline — 신용정보법과 Agent Payments

주 언어: 한국어. 대체: 영어.
분석 대상: 「신용정보의 이용 및 보호에 관한 법률」[시행 2024. 8. 14.]
[법률 제20304호] 및 같은 법 시행령 [시행 2026. 2. 3.] [대통령령 제36074호].

방법: 법·시행령 원문을 law.go.kr에서 직접 추출해 조항별로 대조한 뒤,
Agent Payments 아키텍처의 각 구성요소(데이터 취득 경로, 권한 위임 구조,
판단 자동화, 사업자 지위)에 매핑한다. 금융위원회 보도자료·규제 샌드박스
지정 사례로 현행 감독 실무와 개정 방향을 확인한다.

## 1. 초록
본문 완성 후 작성.

## 2. 서론
- 왜 Agent Payments에서 신용정보법이 결정적인가: 에이전트는 결제 실행
  이전에 반드시 개인신용정보를 읽고 판단해야 하며, 그 지점을 규율하는
  법이 신용정보법이다.
- 범위: 신용정보법 중심. 전자금융거래법·여신전문금융업법·개인정보보호법은
  경계 지점만 언급하고 전면 분석은 범위 밖(별도 리포트 존재).
- 이 리포트는 법률 자문이 아니라 공개 법령·자료에 근거한 리서치라는 명시.

## 3. 배경: 신용정보법의 구조와 규율 대상
- 신용정보·개인신용정보의 정의 구조(§2(1), (1의2)~(1의4)): 식별정보는
  거래내용·신용도·신용거래능력 정보와 **결합될 때만** 신용정보.
- "신용정보회사등"(§15①)의 범위 — 신용정보제공·이용자를 포함하므로
  금융회사가 아닌 사업자도 규율 대상이 될 수 있다.
- 업(業) 허가 체계(§4): 신용정보업·본인신용정보관리업·채권추심업.
- "처리"의 광범위한 정의(§2(13)).

## 4. 조항별 영향 분석 — Agent Payments 아키텍처 매핑
- 4.1 **데이터 취득 경로의 이분법**: 전송요구권(§33조의2)이 정규 경로이고,
  접근매체 기반 열람(§22조의9③ + 시행령 §18조의6③)은 금지 경로다.
  전송요구 대상에서 "별도로 생성·가공한 신용정보"가 제외되는 점(§33조의2②3).
- 4.2 **대리인 구조**(§39조의3 + 시행령 §34조의3): 전송요구·설명요구·
  동의철회·열람정정을 대리인이 행사할 수 있고, 위임은 내용·범위·기간을
  특정해야 한다. 에이전트 권한 모델의 법정 형식.
- 4.3 **위탁 구조**(§17): 수탁자에 대한 직접 의무·벌칙 준용(②),
  식별정보 암호화(④), 교육·계약 반영(⑤), **재위탁 금지**(⑦).
- 4.4 **라이선스 경계**: 본인신용정보관리업 해당성(§2(9의2)) —
  "통합하여 그 신용정보주체에게 제공"이 정의의 핵심.
- 4.5 **자동화평가**(§2(14), §36조의2 + 시행령): 규율 대상은 "사람을
  평가하는 행위"이며 결제의 자동 실행 자체는 아니라는 구분.
- 4.6 **동의 체계**(§32, §33, §34조의2): 처리 단계별 사전 동의 원칙이
  반복적·상시적 에이전트 동작과 구조적으로 충돌하는 지점.

## 5. 제재 리스크의 크기
- 과징금 전체 매출액의 3%(§42조의2①), 항목별 상한.
- 벌칙: 목적 외 누설 10년/1억(§50①), 무허가 영업 5년/5천만(§50②1).
- 위탁 구조에서 수탁자가 지는 직접 책임(§17②).
- 손해배상·법정손해배상(§43, §43조의2)과 상시평가(§45조의5).

## 6. 규제 내 전략
- 단기: 대리인 설계(§39조의3 준거) + 규제 샌드박스 경로.
- 중기: 동의제도 개편 입법 대응.
- 아키텍처 설계 원칙 체크리스트(경로·권한·판단·기록·사업자 지위).
- 피해야 할 안티패턴.

## 7. 규제 변화 동향과 불확실성
- 2026-06-16 금융위 개인신용정보 동의제도 개편 법률자문단 출범과
  AI 에이전트를 명시적 문제 사례로 든 점.
- 2025-12 혁신금융서비스 지정(마이데이터 기반 금리인하요구권 대행 19건).
- 개인사업자 마이데이터와 "금융대리인(My AI Agent)" 구상, 2026년 개정 예정.
- 확정되지 않은 것과 확정된 것의 구분.

## 8. 한계 (Limitations)
- 감독규정·고시 미대조, 유권해석·제재사례 미확인, 개정안 문안 부존재 등.
