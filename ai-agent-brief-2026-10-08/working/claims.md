# Claims

- c01: A throw inside x402's `beforeVerify`/`beforeSettle` extension-gate hooks was only logged, not enforced, so an extension whose check could not complete (decode, signature, commitment) let the payment through — a fail-open bug, filed as issue #3689 on 2026-10-04 and patched in open PR #3702 on 2026-10-05, which makes a throw stop the payment with `extension_hook_error`.
- c02: This is the third correctness/security issue found in an x402 payment primitive within roughly two weeks (two batch-settlement bugs the prior week, now a fail-open gate), a pattern distinct from one-off bugs.
- c03: x402's Go SDK (PR #3726, open, 2026-10-07) adds a facilitator-managed voucher-custody mode to EVM batch-settlement, letting the facilitator rather than the resource server hold, claim, and settle vouchers — an optional mode alongside the existing default.
- c04: x402's `#wg-card-acceptance` working group, including a named American Express contributor, reviewed and narrowed a draft proposal (issue #3706, PR #3707, opened 2026-10-06) to bind credit/debit cards to the existing `auth-capture` scheme as a new network type (`card:<network>`), letting a buyer without a funded crypto wallet pay over x402 via an opaque PSP token and a hold-then-capture flow.
- c05: The card-binding proposal leaves five explicit open questions (agent-only scope, token portability, how card networks recognize an x402-originated transaction, which ID ties hold to charge, and sub-card-fee micropayments) unresolved as of 2026-10-08, so it is a draft under review, not a shipped feature.
- c06: Google announced two MCP-tooling products on 2026-10-07: a Developer Knowledge API plus an official MCP server exposing Google Cloud/Firebase/Android documentation to agents (public preview), and the MCP Toolbox Java SDK reaching v1.0 with credential-handling and parameter-pruning hardening for enterprise use.
- c07: These Google announcements land two days after Ars Technica (2026-10-05) reported independent confirmation that an MCP trust-model flaw researcher had predicted in May 2026 recurred independently across five unrelated organizations (Google, JPMorgan Chase, Weaviate, France's DINUM, and a city government in Indonesia) — a story already covered in the 2026-10-06 brief, cited here only as context for the timing, not as a new item.
