# Claims

- c01: wevm's mppx SDK (co-maintained with Tempo Labs for the Machine Payments Protocol) shipped two releases on 2026-11-16 that add agent-identity machinery to the payment path: an ERC-8004 identity provider (0.20.0) that requires a request's signer to match the wallet an on-chain Identity Registry names, and x402 sign-in-with-x support plus an identity-attestation issuer (0.20.1) that lets a wallet answer a 402 challenge without paying when a signed attestation grants access.
- c02: This moves agent identity verification from a documented-but-unshipped x402 extension (the `sign-in-with-x` spec, previously flagged with an open core-schema bug for auth-only routes) into a released SDK that production servers can adopt today.
- c03: Daydream shipped "Daydream Agent" on 2026-11-17, a stylist agent that can complete a purchase through a one-click checkout flow across a 10,000+ brand catalog — an agent-to-merchant commerce product shipped with no named payment protocol (no ACP, UCP, or x402 reference in the announcement), which is itself a data point about how much of today's agent commerce still runs on undisclosed, proprietary checkout plumbing rather than the open rails this beat tracks.
- c04: Two vertical AI-agent startups raised funding in the window (Model ML: $250M Series B at a $1.5B valuation for banking-analyst agents; Pedestal AI: $4.7M seed for supply-chain/delivery agents), continuing the investment pace into agent tooling the brief has tracked all month, without disclosing the underlying agent frameworks or models in either case.
- c05 (why it matters): The identity/authorization layer (c01, c02) and the commerce layer (c03) are advancing on separate, disconnected tracks this week — an open SDK is shipping real agent-identity verification while a shipped consumer agent completes real purchases with no visible standard underneath — which is the same gap prior editions have flagged: infrastructure for trusting and authorizing agents is maturing faster than the commerce products built on top of it are adopting it.
