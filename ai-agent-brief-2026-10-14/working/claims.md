# Claims

c01. Shopify announced on 2026-10-13 that shoppers can configure their own AI agents to purchase from Shopify's catalog on their behalf, expanding beyond the browser-agent checkout access it opened on 2026-09-28, and giving more agents access to over a billion catalog listings.

c02. Google's Agent Development Kit (ADK) is now available as production SDKs in five languages (Python, Go, TypeScript, Java, Kotlin) as of 2026-10-14, each interoperable via shared MCP and A2A (Agent2Agent) support, with Go and TypeScript running Python's ADK 2.0 Graph Workflow runtime.

c03. Pluto Security raised a combined $42M ($8.5M seed + $34M Series A) disclosed 2026-10-13, to monitor and intervene on AI agent behavior inside enterprises — not just user behavior — including mid-task permission escalation.

c04. None of the named agent payment-protocol specs (x402, AP2, ACP, UCP, MPP, L402, Trusted Agent Protocol) produced a notable shipped change in this window; x402-foundation/x402 and AP2 both show only routine, unmerged or incremental PR activity.

c05. The through-line across this window's three items is a shift from platform-controlled agent access toward user- and developer-configured agent access, on both the commerce side (Shopify) and the tooling side (ADK), while enterprise security correspondingly shifts from policing users to policing agents (Pluto).
