## 4. 아키텍처: 세 개(또는 네 개)의 축 (Architecture — the pillars)
- Umbrella Lean Ethereum: lean consensus / lean data / lean execution.
- leanroadmap.org's Lean Consensus framing: consensus / cryptography / governance / craft.
- Lean Consensus internals: 3-Slot Finality (3SF), Goldfish fork choice, Attester-Proposer Separation (APS), exit-queue redesign, slot timing.
- Lean Cryptography: hash-based signatures (XMSS-family, `leanSig`), `leanMultisig` aggregation, Poseidon2 cryptanalysis, FRI/WHIR/STIR proof systems.
- Lean Data: DAS/PeerDAS successors, short data-retention windows, PQ-safe commitments.
- Lean Execution: minimal SNARK-friendly VM (RISC-V direction), and its relation to EVM.
