# Claims — ai-agent-brief-2026-10-20

- c01: NorForge's scan of exposed Cairn control panels found three distinct clusters (AIA0001: 14 panels, Chinese-language, 1,100+ attack projects; AIA0002: 10 panels, English-language; AIA0003: 1 panel, low confidence) with an average per-task success rate around 10%, moving Cairn from a disclosed proof-of-concept tool (Gambit Security, September 2026) to a toolkit independently found running live intrusion campaigns against named production companies.
- c02: Reuters' reporting that Deere, SharkNinja, and Cummins were each breached through the same exposed-panel campaign is the first time named, identifiable victims have been attached to this specific AI-agent hacking cluster, as opposed to the sector-only descriptions in NorForge's own technical writeup.
- c03: Microsoft's Guardian Agents launch, paired with Nadella's public statement that enterprises should not trust any model provider's own safety assurances, moves Microsoft from building agent safety as an extension of its AI partners' trust (the original framing of Project Perception in June) to building it as an explicitly adversarial, provider-independent check.
- c04: The Nvidia Open Agent Safety Platform's hardware-level containment, with 100+ member companies but a visible absence of OpenAI, shows the agent-oversight-independence argument gaining multi-vendor backing precisely among Microsoft's and OpenAI's competitors and partners, not inside OpenAI's own stack.
- c05: OpenCode's breach disclosure — 1.4% of Console users, four-figure unauthorized charges on OpenAI/Anthropic/Google accounts, and a disputed "distillation attack" framing — demonstrates that long-lived API keys stored in a console remain the live attack surface for agent coding tools, independent of whether the underlying open-source CLI itself was compromised.
- c06: The pattern across July (Hugging Face), September–October (India's CERT-In, the Cairn campaign) and OpenCode's incident response is that commercial AI providers' own safety filters have repeatedly refused to help incident responders analyze the malicious code or agent logs from these same incidents, a recurring failure mode rather than a one-off.
