# Claims
- c01: Shopify's Shop Pay checkout is now reachable by Meta's Muse agent, and eligible US merchants are enrolled by default with a manual opt-out, so agent checkout reaches roughly a million stores without per-merchant integration (s01, s02).
- c02: Danske Bank and Mastercard completed a booking and payment by an AI agent on Danske-issued card rails on 2026-09-21, using Agent Pay tokens and Payment Passkeys, as a controlled proof of concept (s03).
- c03: GoCardless ran a live agentic account-to-account payment (a recurring donation to Trussell) in the UK under the FCA's AI Live Testing programme, extending agent payments beyond cards (s04).
- c04: Google Cloud API Gateway, in public preview, can front an OpenAPI REST API as a remote MCP server that reuses the API's existing JWT or API-key auth, but tool discovery cannot be protected by an API key (s05).
- c05: Google's Gemini can place phone calls to businesses for a user, starting with paid-subscriber Pixel 11 owners in the US (s06).
- c06: Today's payment items all ride existing infrastructure (a checkout button, card tokens, direct debit), so distribution and default settings, not new protocols, decide who gets agent traffic (s01, s03, s04).
