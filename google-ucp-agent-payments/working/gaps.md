# Gaps

- Wire-level UCP message schemas (exact JSON fields, error model, JSON-RPC method names beyond `create_checkout` and catalog search) are referenced in the GitHub spec but were not directly extracted as quotes here; treated as configuration-level detail outside the report scope.
