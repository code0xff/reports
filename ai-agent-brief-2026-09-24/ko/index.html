초록

구글 Antigravity SDK가 로컬 모델만으로 에이전트 루프를 돌릴 수 있게 됐고, ChatGPT 모바일 앱에 음성 기반 에이전트 작업이 들어왔으며, Rabbit은 R1 기기 없이 쓰는 소프트웨어로 에이전트를 다시 내놓았다. 결제·신원 쪽에서는 오늘 기준을 넘긴 소식이 없어서, 이번 브리프는 에이전트가 어디서 돌고 누구의 키를 쓰는가에 집중한 짧은 판이다.

소개

이번 ai-agent-brief는 2026-09-21부터 2026-09-24까지 72시간을 다룬다. 고정 주제는 에이전트 프레임워크와 개발 도구, 에이전트 결제 프로토콜, 카드사와 PSP의 에이전트 상품, 에이전트 신원, 그리고 표준화 기구다. 지난 브리프는 아마존의 Muse 차단과 x402 경로 매칭 패치를 다뤘고, 둘 다 이번 기간에 새 전개가 없었다. 14일치 URL 중복 제거와 사건 단위 묶기를 거쳐 새 항목 세 건이 남았다.

무슨 일이 있었나

Antigravity SDK, 로컬 모델 지원

구글은 9월 23일 코딩 에이전트 제작 도구인 Antigravity SDK에 로컬 모델 지원을 추가했다[1]. 처음 최적화된 대상은 LiteRT로 돌리는 Gemma 4 26B A4B이고, OpenAI 호환 서버라면 Ollama, LM Studio, vLLM 모두 연결된다. 구글 시연에서는 토큰의 97.2%(3,322개)가 로컬에서 생성됐고, 홍보 문구는 API 비용과 호출 제한 없이 코드가 기기 밖으로 나가지 않는다는 것이다[1]. 요구 사양은 VRAM 또는 통합 메모리 24GB 초과라서 대부분의 노트북은 해당하지 않는다. 로컬 모델과 클라우드 모델을 섞는 구성도 지원한다 (vendor-stated).

개발자에게 가장 실질적인 항목이다. 오프라인으로 도는 에이전트에는 결제 프로토콜을 붙일 종량제 API 자체가 없으므로, x402나 MPP가 전제하는 호출당 결제 구도 밖에 있다.

ChatGPT 모바일, Work 탭과 음성 작업

OpenAI는 9월 23일 ChatGPT 모바일 앱에 에이전트 기능을 넣었다[2]. Plus와 Pro 가입자는 Work 탭에서 음성으로 문서와 이메일 초안 작성, Slack 메시지 요약, 웹사이트와 프레젠테이션 제작, 클라우드 브라우저 사용을 시킬 수 있다. 폰에서 시작한 작업을 데스크톱에서 이어갈 수 있고, 무료와 Go 사용자에게는 플러그인과 연결 앱이 열린다 (unverified — single source). TechCrunch는 7월의 GPT-Live 출시와 이어지는 기능으로 소개했다.

Rabbit, OS3를 소프트웨어로 출시

Rabbit은 9월 22일 OS3를 Windows, Mac, Linux용으로 정식 공개했다. 브라우저, 텔레그램, iMessage/RCS/SMS, R1로 접속한다[3]. 계정 하나에 기기 다섯 대까지 연결하고, 에이전트가 지시를 기억하며 백그라운드에서 작업한다. 사용자가 자기 API 키나 로컬 모델을 가져오는 방식이라 에이전트 자체의 월 구독료는 받지 않는다 (unverified — single source). 데스크톱 소프트웨어를 조작하는 에이전트의 흔한 위험, 즉 권한과 로그인, 그리고 사이트 레이아웃이 바뀌면 흔들리는 작업이 기사에서 지적됐다[3]. 발표문은 OS3의 권한 관리 방식을 거의 설명하지 않는데, 로컬 파일에 손댈 수 있는 만큼 채팅 앱보다 이 부분이 더 중요하다.

왜 중요한가

세 건 중 두 건은 모델 선택권을 사용자에게 두고, 세 건 모두 호출마다 요금을 매기지 않는 곳에서 에이전트를 돌린다. 에이전트가 남의 서버의 유료 엔드포인트를 호출한다고 전제한 사이트의 기존 에이전트 커머스 보고서와는 그림이 다르다. 로컬·자기 키 방식이 퍼지면 판매자도 카드사도 결제 대행자도 끼지 않는 에이전트 활동이 늘고, 신원 문제는 에이전트가 자기가 돌아가는 기기에서 무엇을 해도 되는가로 옮겨간다.

지켜볼 신호

  • 실제 저장소에서 Antigravity 로컬 모드를 독립적으로 시험한 결과. 지금 수치는 구글 시연뿐이다.
  • OS3가 일반 사용자에게 가기 전에 권한을 어떻게 다루는지.
  • 내일은 결제나 신원 쪽 발표가 돌아올까? 오늘의 공백은 추세가 아니라 데이터 한 점이다.

한계

이번 기간에는 결제 프로토콜, 카드사, 에이전트 신원 소식이 기준을 넘지 못했고 Bluesky와 Reddit 레인은 쓸 수 없었다(working/gaps.md 참조). 세 항목 중 두 건은 기사 한 건에 의존한다. Cloudflare의 Worker Previews(9월 22일)는 에이전트와의 연결이 고객 인용에만 있어 제외했다.
