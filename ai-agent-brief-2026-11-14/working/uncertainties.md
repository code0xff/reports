# Uncertainties

- ChatGPT Wallet's rollout scope ("a limited number of U.S. ChatGPT Pro subscribers") is vendor-stated with no count given; TechCrunch did not independently verify how many users have access today.
- Which specific card issuers support ChatGPT Wallet beyond "U.S.-issued Visa, Mastercard, or American Express" is unconfirmed — no issuer list was published in either source read this run.
- UCP's Food Checkout spec is explicitly labeled "Draft — Work in Progress" with a warning of further breaking changes, despite the "coming soon" banner coming down; whether that is a cosmetic go-live or a commitment to API stability is not stated by the source.
- No named retailer (DoorDash, Square, Toast, Uber Eats — all logo'd on UCP's homepage as "co-developed by industry leaders") is confirmed to be live on Food Checkout; the logos indicate co-development participation, not production use.
- mppx's three identity PRs this window build out real primitives (remote signing, Tempo ID, World ID) but none is yet paired with a production deployment or adopter named in the PRs themselves — this is SDK capability, not evidence of uptake.
