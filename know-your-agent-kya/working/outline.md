# Outline — Know Your Agent (KYA)

1. 초록
2. 서론 — 용어의 기원(Skyfire KYAPay, 2024)과 2026년의 확장된 쓰임, 이 보고서의 범위
3. 배경 — KYC가 답이 안 되는 이유: 위임(on-behalf-of), 에이전트와 사용자 구분, 책임 사슬
4. 상용 구현 — Mastercard Agent Pay(Agentic Token + KYA 등록, Verifiable Intent), Visa Trusted Agent Protocol(Verified Agent ID), Google AP2(mandate), Cloudflare Web Bot Auth, Skyfire, Sumsub 등 신원 벤더
5. 표준화 — FIDO(Payments/Agentic Authentication TWG), DIF Trusted AI Agents WG(MCP-I → KYA-OS), OpenID AuthZEN, IETF WIMSE, OAuth 확장
6. 학술 연구 — Authenticated Delegation, BIND(생체 바인딩), 에이전트 신원 관리, 다중 에이전트 권한 전파, DID/VC 기반 에이전트
7. 분석 — KYA를 구성하는 층(신원·권한 바인딩·런타임 제어·감사)과 미해결 문제(전역 유일성, 책임 귀속, 규제, 벤더 난립)
8. 한계
9. 참고문헌(자동)
