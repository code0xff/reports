# Gaps

- CERT-In did not name which AI providers or which Indian organizations were affected, and did not say whether any agent altered data rather than only reading it. There is no independent (non-voluntary) confirmation of the incident's scope.
- An initial scouting pass treated "Amazon blocks Meta's Muse" and The Verge's October 17 "Websites are closing their doors to AI agents" as this window's third item. On closer check, the underlying block dates to late September and Cloudflare's crawler-default change to September 15 — the Verge piece is a trend synthesis of three-to-five-week-old developments, not a new event in the 72-hour window, so it was dropped in favor of the Cloudflare/OpenAI discovery-pilot disclosure, which is dated within the window. The Amazon/Muse story and the Web Bot Auth / Trusted Agent Protocol identity-standard response to it remain a live sub-beat worth picking up if it produces a dated development (a resolution, a new blocked site, a published spec) in a future window.
- Cloudflare and OpenAI's "hundreds of millions of pages" figure and the "roughly 1%" pilot footprint come only from the two companies' joint announcement; no third party has measured either number.
- No payment-protocol-specific news (x402, AP2, ACP, UCP, MPP, L402, Trusted Agent Protocol) surfaced in this window beyond continuing, already-covered PR activity on x402's receipt-linkability spec (PRs #3827/#3830, both still open, unchanged from the prior edition) and routine doc/bugfix PRs. AP2's repository remains dormant since April 29, 2026.
- google/adk-recipes' GitHub metadata shows the repository itself was created April 1, 2025; the launch being covered this window is the blog-announced restructuring (three-layer plugin spec, machine-readable manifests), not the repository's first existence.
