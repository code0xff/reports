# Uncertainties — x402-siwx

- **확장 스펙의 신선도**: SIWX 확장은 x402 V2(2025-11 전후)와 함께 정비된 신규 표면으로, 필드·API가 아직 변할 수 있다. 본 리포트의 코드 인용은 2026-07-06의 main 브랜치 스냅샷.
- **채택 데이터 부재**: SIWX를 실제로 켠 프로덕션 리소스 서버의 공개 목록/지표를 확인하지 못함. "생태계 채택" 서술은 프로토콜 전체(x402) 수준의 지표에 의존.
- **Go/Python 구현 동등성**: 파일 트리와 문서 예제로 존재는 확인했으나, TS와의 동작 동등성(특히 검증 규칙 세부)은 코드 정독 미수행 — vendor-stated.
- **"100M+ 결제" 등 성장 지표**: Coinbase/재단 측 서술로 독립 감사 없음 — vendor-stated.
- **SIWX 자체에 대한 독립 비평 부재**: 신규 확장이라 외부 보안 리뷰가 아직 없음. 보안 분석은 SIWE/ERC-1271 계열의 알려진 위험을 유추 적용한 것임을 본문에 명시.
- **nonce 처리의 이중성**: 서버가 매 402 응답마다 fresh nonce를 내리지만, validateSIWxMessage의 기본 경로는 nonce 저장 없이 시간 경계만 검사(옵셔널 checkNonce/hasUsedNonce). "동일 헤더 재사용" 윈도우(기본 5분)가 실제 얼마나 위험한지는 배포 환경(TLS, 프록시 로깅 등)에 따라 다름 — 해석적 판단.
