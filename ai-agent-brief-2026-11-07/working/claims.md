# Claims

- c01: Zalando open-sourced the Agentic Identity Broker (AIB) under the MIT license on 2026-11-06, an OAuth2 broker that lets a user grant an AI agent scoped, revocable access to MCP services without handing the agent the user's own tokens, and the project already runs in production inside Zalando on "hundreds" of agents against "dozens" of internal and external MCP servers.
- c02: AIB's delegation mechanism stores third-party tokens encrypted inside the broker itself — never releasing them to the agent — and has a gateway (e.g. Agentgateway) perform an RFC 8693 token exchange at request time, which moves Zalando's design closer to "agent authenticates as itself, broker vouches for the user" than to "agent holds a copy of the user's credential."
- c03: mppx shipped built-in Durable Object and SQL (Postgres/SQLite/D1) storage backends for its session/channel state on 2026-11-06, specifically to make `tempo.session()` channel state and replay protection work when mppx runs as a Cloudflare Worker.
- c04: mppx also exposed two settlement-recovery primitives on 2026-11-06 — a typed `BroadcastOutcomeUnknownError` carrying the signed transaction hash after an ambiguous broadcast, and a `stripe.recordPayment` helper — so integrators can recover a settlement mppx itself failed to record, instead of reimplementing mppx's internal recovery logic.
- c05: mppx's PR #1202 (merged 2026-11-06) adds a typed `PaymentSimulationError` tagging whether a failed Tempo fee-sponsorship preflight failed in the `sender` or `sponsored` phase, closing the exact diagnostic gap that made Monday's (2026-11-05) sponsored-payment outage take hours to attribute to a node upgrade rather than a balance or deploy problem.
- c06: No card-network or PSP agent-commerce product (Mastercard Agent Pay, Visa Trusted Agent Protocol, Stripe's Agentic Commerce Protocol, PayPal) and no activity in AP2's or UCP's canonical repos produced a dated primary item inside the 2026-11-05–2026-11-07 window.
