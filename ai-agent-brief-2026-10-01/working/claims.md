# Claims

- c01: Cloudflare's Monetization Gateway (closed beta, launched 2026-09-30) lets a domain owner charge AI agents per request using HTTP 402, settling in USDC on Base via the x402 protocol — a shift from subscription/API-key access control to per-request metered pricing set by the publisher, not the platform.
- c02: Four named production users (Cloudflare AI Gateway, Ceramic.ai, Stocktwits, API2PDF) are already charging through the gateway during the closed beta, which puts x402-style payments into production use rather than only pilot/demo status.
- c03: DoorDash's text-to-order agent (announced 2026-09-30, US waitlist) routes ordering entirely through Apple Messages with no dedicated payment or identity protocol disclosed — agent commerce arriving through a conversational surface layered on DoorDash's existing checkout, not a new payment rail.
- c04: Restate's $20M Series A (announced 2026-09-30, led by Singular) is framed explicitly around AI agent workloads needing durable, crash-resilient execution because agent workflows run longer and take less predictable paths than conventional software — positions Restate against Temporal in a segment now large enough to draw distinct competing investment.
- c05: Google Cloud shipped two separate agent-tooling releases on 2026-09-29/30 — a remote MCP server for the Cloud CLI (preview) and general availability of Data Agent Kit — both aimed at letting any coding agent reach Google Cloud resources and data without custom integration code, continuing the MCP-as-integration-layer pattern seen across the beat.
- c06: The card-network/PSP agent-commerce payment-protocol layer named in this beat (x402, AP2, ACP, UCP, MPP, L402, Trusted Agent Protocol) produced no in-window spec change; the one repo with in-window activity (tempoxyz/mpp-specs) shows only CI configuration commits, matching the pattern from the prior four briefs.
