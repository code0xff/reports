# Uncertainties

- Whether "specialist dots" identity/credentialing actually functions as a general-purpose agent-identity system, or is scoped narrowly to OpenAI's own enterprise pilots (procurement, invoicing, customer support) — the blog post describes focused pilots, not a broad rollout, so the identity model's reach is unproven.
- Whether x402's new delegated-caller-identity mechanism in the Go SDK is adopted by any production facilitator beyond the reference implementation; the PR is an SDK capability, not evidence of live usage.
- Whether the MPP and x402 merges mark a real re-acceleration of spec work or are isolated maintenance commits; one data point in each repo is not yet a trend, and both specs could go quiet again next edition.
- Photon's "agents replace apps" thesis is a seed-stage company's framing of its own market; messaging-channel agents replacing mobile apps broadly remains unproven at the market level, independent of Photon's reported traction.
