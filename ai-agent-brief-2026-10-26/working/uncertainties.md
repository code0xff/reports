# Uncertainties

- The agent-messaging proposal (#3943/#3944) is single-author, same-day, and backed by a reference implementation in a repository with zero stars and no independent users. It is an early signal of interest in an agent-to-agent messaging layer for x402, not evidence that the extension will be adopted, or even reviewed, by the Foundation.
- The claim that the same spec is "under review" on the Solana Foundation's fork (PR #71) rests on that PR's title alone; its body is a default template with no description filled in, so the depth of that review, if any, could not be assessed.
- PR #3935's claim that the bug does not affect the TypeScript SDK (because TS already filters V1 registrations) is the PR author's own framing and was not independently re-verified against the TypeScript source in this pass.
- UCP's return-policy extension is a schema and spec addition; no production merchant integration or agent-client adoption of it was found in this window, so it is a protocol-level development, not yet a deployed one.
