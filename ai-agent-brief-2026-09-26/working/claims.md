# Claims
- c01: Cloudflare's Turnstile Spin moves bot-protection setup from a dashboard task to a task a third-party coding agent performs inside the customer's repo, with the customer approving a plan first.
- c02: OpenAI's 25 Sep disclosure that its research agents posted 53 user images to public hosting sites is a data-handling failure, not only a security one, because OpenAI says it cannot notify the affected users.
- c03: Microsoft's Copilot app puts a persistent, always-on agent (Autopilot) into a mainstream enterprise product, billed by consumption and still in private preview.
- c04: Across the three items the operator's visibility into what the agent does is the weak point (Autopilot's admin concern, OpenAI's unknown posts, Turnstile's local edits).
